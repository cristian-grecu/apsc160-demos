The Fisher–Yates shuffle

Shuffle an array in place so that every order is equally likely: walk from the back, and swap each position with a random one that hasn't been placed yet.

Part 2

A common mistake: picking from the whole array

This version looks almost the same, but j can land anywhere, including on positions already placed:

for (int i = 0; i < n; i++) {    int j = rand() % n;          // 0 .. n-1, every time    char temp = a[i];    a[i] = a[j];    a[j] = temp;}

Take n = 3 and the array 'a', 'b', 'c'. Count every possible run:

  • Fisher–Yates: j has 3 choices, then 2: 3 × 2 = 6 runs for 6 orders. Each order comes out exactly once.
  • Biased version: j has 3 choices, three times: 3 × 3 × 3 = 27 runs for 6 orders. 27 ÷ 6 isn't a whole number, so some orders must come up more often than others.

Biased version

For n = 3 the biased version gives each order 4/27 ≈ 14.8% or 5/27 ≈ 18.5% instead of 16.7%, and the unevenness gets worse as n grows. Fix: pick j only from the part not yet placed, rand() % (i + 1), and count i down.
